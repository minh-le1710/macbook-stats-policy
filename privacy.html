1. Strict Zero Data Collection

MacBook Stats Overlay was architected from line one to be an offline-first, local-only system monitor. We believe your hardware metrics are your personal property. We do not operate remote servers, we do not collect IP addresses, and we do not track when or how long you use the application.

2. Local-Only Hardware Telemetry via Public Apple APIs

All hardware statistics displayed within the overlay and menu bar gauges are retrieved directly on your Mac using public Darwin, Mach, and IOKit APIs provided by macOS:

  • CPU & Apple Silicon Core Topology: Retrieved via Darwin Mach kernel host_statistics(HOST_CPU_LOAD_INFO) and public sysctl keys (hw.perflevel0.physicalcpu and hw.perflevel1.physicalcpu) to identify Performance and Efficiency cores.
  • Metal GPU & Unified Memory: Queried through official Apple Metal public interfaces (MTLCreateSystemDefaultDevice) and read-only IOKit IOAccelerator device utilization properties.
  • RAM & Memory Pressure: Read through Mach VM statistics (host_statistics64(HOST_VM_INFO64)) for active, wired, and compressed page counts.
  • Battery Physics & Real-Time Discharge: Retrieved via public IOPSCopyPowerSourcesInfo and standard read-only AppleSmartBattery service keys (InstantAmperage, Voltage, AvgTimeToEmpty) to measure live discharge wattage without guessing.
  • Network Transfer Rates: Calculated via standard Darwin getifaddrs() byte deltas on active physical interfaces (ifi_ibytes / ifi_obytes). Note: The app does NOT inspect packets, does NOT inspect payloads, and does NOT monitor your web traffic.
  • Thermal State: Monitored via standard ProcessInfo.processInfo.thermalState.

All calculated data is retained volatilely in RAM only for the duration of the rolling graph buffer (e.g. 60 seconds) and is never written to disk or transmitted to any server.

3. macOS App Sandbox Compliance

MacBook Stats Overlay complies strictly with Apple's macOS App Sandbox security architecture:

  • No kernel extensions (KEXTs) or driver extensions are installed.
  • No SMC write operations or unauthorized hardware modifications are executed.
  • No outbound network server connection is initiated.
  • The application runs fully isolated with minimum required privileges.
