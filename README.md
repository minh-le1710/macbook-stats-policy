## 🛡️ App Store Privacy Declaration Summary

- **App Privacy Nutrition Label:** **Data Not Collected**
- **Telemetry Architecture:** 100% local-only queries via Darwin Mach kernel, IOKit, sysctl, and Metal public APIs (`host_statistics`, `host_statistics64`, `IOAccelerator`, `AppleSmartBattery`).
- **Network Access:** Zero outbound analytics, tracking, or telemetry endpoints.
- **Security:** 100% Apple macOS App Sandbox compliant.
